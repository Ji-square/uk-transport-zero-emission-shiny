# UK Transport Zero-Emission 2040 — Shiny app

Interactive app that tracks the UK's progress towards zero-emission transport.
It maps charge points and transport CO2 emissions by country, and plots electric
vehicle registrations and electricity generation over time.

MSc Data Analytics project, London Metropolitan University (2022).
Author: Eduard de Jesús Romero Mercedes. Supervisor: Prof. Hassan Kazemian.

Live app: https://0d5iyx-eduard-romero0mercedes.shinyapps.io/Msc_Project-1/

## Structure

| File | Purpose |
| --- | --- |
| `prepare_data.R` | Reads the raw datasets (~90 MB), cleans and aggregates them, and writes `data/app_data.rds` (~0.6 MB). |
| `data/app_data.rds` | Pre-processed data, the only data the app loads. |
| `app.R` | Shiny UI and server. |
| `estilos_.css` | Styles for the floating control panel. |
| `docs/` | Full MSc dissertation (PDF), with the original code as an annex. |

## Data sources

All raw data are open UK Government datasets:

- National Chargepoint Registry
- UK local authority and regional greenhouse gas emissions, 2005–2020 ([data.gov.uk](https://www.data.gov.uk/dataset/723c243d-2f1a-4d27-8b61-cdb93e5b10ff/uk-local-authority-and-regional-greenhouse-gas-emissions))
- Vehicle licensing statistics, ultra-low emission vehicles ([gov.uk](https://www.gov.uk/government/statistical-data-sets/vehicle-licensing-statistics-data-tables))
- Subnational electricity consumption statistics, 2005–2020, and electricity generated by source
- Country boundaries (ONS Open Geography Portal)

## Run locally

```r
install.packages(c("shiny", "shinyWidgets", "leaflet", "sf", "dplyr", "ggplot2"))
shiny::runApp()
```

To rebuild `data/app_data.rds` from the raw files, also install `tidyr`, `readr`
and `readxl`, place the raw files next to `prepare_data.R` and run
`source("prepare_data.R")`.

## Deploy to shinyapps.io

```r
rsconnect::deployApp(
  appName  = "Msc_Project-1",
  appFiles = c("app.R", "estilos_.css", "data/app_data.rds")
)
```
